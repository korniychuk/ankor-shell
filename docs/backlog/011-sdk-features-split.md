# 011 — Завершить разделение `sdk/` ↔ `features/`

## Задача
Проверить модули `sdk/` и вынести в `features/` то, что по сути фича, а не библиотечный helper. Оператор: «судя по всему, у меня не закончено разделение между SDK и Features директориями … в SDK попала … некоторые вещи, которые выглядят как фичи».

## Желаемый результат
Критерий «sdk vs feature» зафиксирован; фичи-модули лежат в `features/`, `index.sh`/completions/CLAUDE.md (таблица модулей) согласованы.

## Контекст / зацепки
- Пример оператора: «IC-утилита, которая интернет-чек» (`ak.inet.check`, `sdk/inet.sh`) — «выглядит как будто должна лежать в Features». Связано: [[00e-inet-check-parallel-diagnostics]], [[00d-inet-ping-quit-key]].
- Уже в `features/`: `sudo.sh`, `sudo-remote.sh`, `sudo-remote-many.sh`.

## Склонности оператора
- «Возможно, просто миграция на директорию SDK не была закончена.»
