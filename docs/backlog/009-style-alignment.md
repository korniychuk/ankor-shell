# 009 — Style alignment sweep по всем модулям

## Задача
Финальный проход по всем `*.sh`: привести код к конвенциям 002 под контролем линтеров (003) и smoke-тестов (004). Выполняется ПОСЛЕ 002–008, чтобы не переделывать дважды.

## Желаемый результат
- Единый стиль определения функций: `function name() {` (устранить `ak.rnd.minute()` без keyword, `ak.array.joinBy` без скобок).
- `[[ ]]` везде вместо `test`/`[ ]` (`sdk/os.sh` целиком, `sdk/shell.sh:67`; исключение — строки внутри `git filter-branch` env-filter, там `sh`).
- Дисциплина переменных: `local -r`/`local -ri` (единый вариант написания), не-readonly только где мутируется.
- Все модули используют `ak.sh.ok/warn/err/die` (005) вместо ad-hoc `echo '...Error...' >&2` (git.sh, inet.sh, сам shell.sh).
- Doc-комментарии всех публичных функций приведены к канону 002 (ограждение `##`, единые теги/типы) — prerequisite для генератора 00a; недокументированные публичные функции задокументированы.
- Naming-решения по существующим отклонениям (`ak.sh.clear-line`, `ak.sh.test-drive`, домен `ak.node-loader.*` с дефисом): новые имена по конвенции + старые как deprecated-алиасы на переходный период (ничего не ломать молча).
- Мелочи: mis-indents (`cals.sh:72`, `shell.sh:146`), `echo -e` → `printf`-паттерн там, где решим в 002.

## Контекст / зацепки
- Полный список зафиксированных расхождений с file:line — в отчёте разведки (продублирован в `ankor/hardening-ref-notes.md`).
- **CaLS-инварианты неприкосновенны** (см. 002): содержимое генерируемых обёрток менять только синхронно с механизмом инвалидации из 008.
