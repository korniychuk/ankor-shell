# Research: готовые пакеты vs sdk/dt.sh

## Вопрос
Есть ли готовый пакет для macOS/Debian/Ubuntu, который делает на 100% то же, что `sdk/dt.sh`? И стоит ли переписывать `dt.sh` на Rust (в рамках обсуждения «Rust/Bun для сложных частей репо»).

## Анализ dt.sh
Модуль тонкий (~50 содержательных LOC). Вся функциональность:

1. **Резолвер GNU-совместимого `date`** (`__ak.dt.resolveDateBin`, кэшируется):
   `date` (GNU/uutils, Linux) → `gdate` (brew coreutils, macOS) → внятная ошибка
   с подсказкой `brew install coreutils`. Принимает и uutils-coreutils
   (Rust-реимплементация, дефолт Ubuntu 25.10+).
2. **Шесть пресетов формата**: `ak.dt.now`, `.now.date`, `.now.time`,
   `.now.timestamp`, `.now.ms`, `.now.iso` — однострочники над `__ak.dt.gdate`.
3. `ak.dt.isDateValid` — валидация через `date -d`.

100% реальной работы делегируется GNU coreutils `date`.

## Ответ: пакеты

- **GNU coreutils** — и есть тот самый пакет; `dt.sh` уже является тонкой обёрткой
  над ним. macOS: `brew install coreutils` (`gdate`); Debian/Ubuntu: дефолт;
  uutils-coreutils — GNU-CLI-совместим для нашего использования.
- **dateutils** (brew + apt) — единственный настоящий кросс-платформенный
  date-toolkit (`dconv`, `ddiff`, `dadd`, `dround`, `dtest`, `strptime`),
  одинаковое поведение на обеих ОС. Но: всё равно устанавливаемая зависимость,
  другой CLI, и в Debian бинарники с префиксом `dateutils.dconv`, а в brew без —
  резолвер имён понадобился бы снова. Имеет смысл ТОЛЬКО при появлении задач
  date-арифметики (diff, ranges, округления).
- Пресеты-мнемоники (`%Y-%m-%d %H:%M:%S`, ISO 8601, epoch-ms) как короткие
  команды не поставляет ни один пакет — это личная конвенция, и она уже
  реализована оптимально.

## Выводы

1. **Ничего не менять**: `dt.sh` — правильная архитектура (тонкие пресеты +
   резолвер над coreutils). Готовый пакет «на 100%» — сам coreutils, он уже внизу.
2. **dt.sh снят со списка Rust-кандидатов.** Ранее предполагалось, что chrono
   уберёт GNU/BSD-развилку, но развилка уже решена резолвером в 20 строк (кэш,
   uutils, внятная ошибка). Rust-бинарник заменил бы 50 строк bash на бинарник +
   дистрибуцию ради нулевого выигрыша. Актуальный список кандидатов на Rust
   (multitool `akx`, см. обсуждение Rust/Bun): git-redate машинерия из `git.sh`,
   генератор документации (00a), Perl-регексы из `str.sh`.
3. **TODO `dt.sh:5` («Check GNU Date installed») устарел** — проверка давно
   реализована в `__ak.dt.resolveDateBin` с graceful-ошибкой. В задаче 008
   (триаж TODO) — просто удалить. Закоммент-заглушка `ak.dt.normalizeDate`
   (`dt.sh:30-39`, TODO «Finish») — решить в 008: реализовать или удалить.
